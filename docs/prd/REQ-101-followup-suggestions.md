# REQ-101 【猜你想问】机器人回答后推荐 3 个相关追问

- 优先级：P1
- 提出人：产品经理
- 状态：待开发（本次演练的需求来源）
- 关联：`docs/prd/REQ-101`

## 背景

灰度期数据显示，约 38% 的用户转人工是因为"不知道还能问什么"，而非问题解决不了。
在每次机器人回答后给出 3 个与当前话题相关的追问，可以显著提升 AI 自助解决率。

## 需求描述

机器人返回回答时，附带最多 3 条"推荐追问"。用户点击后直接作为新问题发送。

## 验收标准（逐条可检查）

1. 回答结果中返回 `suggestions` 字段，长度 ≤ 3
2. 推荐内容必须与本次识别的意图相关（如物流意图不能推荐发票问题）
3. 识别不出意图（OTHER）或已转人工时，`suggestions` 返回空列表
4. 每条推荐不超过 12 个字，可直接作为用户提问被本系统正确识别（闭环可问）
5. 现有全部单测与评测集仍通过（不得回归）

## 不做的事（明确边界）

- 不做个性化推荐（不基于用户历史）
- 不做点击率统计上报（下一迭代）
- 不改前端渲染

## 技术提示

- 在 `service._reply` 附近扩展，保持既有返回结构兼容
- 建议新增 `suggestions.py`，一个函数 `suggest(intent) -> list[str]`
- 推荐话术本身要能被 `detect_intent` 识别，否则用户点了回答不了（验收标准第 4 条）

## 风险

| 风险 | 对策 |
|------|------|
| 推荐内容答不上来，体验更差 | 验收标准 4 强制"闭环可问"，测试里校验 |
| 撑破 UI 布局 | 数量硬限制 ≤ 3 且每条 ≤ 12 字 |
